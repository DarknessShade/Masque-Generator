## ✨ What is this?

**MASQUE Config Generator** is a lightweight, fully client-side web app (one `index.html` file, no build step, no backend of its own) that:

1. **Requests a fresh WARP MASQUE account** (private key, endpoint public key, tunnel IPv4 / IPv6) from a pool of public APIs, or lets you import an existing one.
2. **Lets you tune every important parameter**: client, transport, endpoint, port, SNI, DNS, fragment masking, noise, MTU, routing rules, and more.
3. **Builds ready-to-use configs live** and lets you copy or download them with one click.

No terminal, no manual JSON editing, no key conversion: open the page, press a button, paste the result into your client.

> 🔗 **Live tool:** https://darknessshade.github.io/Masque-Generator/

<img src="https://github.com/DarknessShade/DarknessShade/blob/main/Image/divider.png?raw=true" width="100%" alt="divider">

## 🧠 What is MASQUE?

**MASQUE** (Multiplexed Application Substrate over QUIC Encryption) is an IETF family of standards for tunneling traffic (UDP, IP, HTTP) through HTTP/3 and QUIC. Cloudflare WARP supports MASQUE as a tunnel protocol alongside WireGuard. Because MASQUE traffic looks like ordinary HTTPS / HTTP/3 traffic to a Cloudflare endpoint, it is a useful alternative where plain WireGuard handshakes are blocked or throttled.

This tool takes a WARP MASQUE account and wraps it into **Xray-core outbounds** (and Clash / Shadowrocket formats) so that you can use it from the clients you already have.

## 🧭 Step-by-Step Guide

### Step 1: Generate a WARP MASQUE key

- Click **Generate new key**. A new account is requested from the API pool.
- The four API chips below the button show the pool status: next in line, used successfully, or failed.
- The following fields are filled in automatically:
  - **Private key (base64)**
  - **Endpoint public key**
  - **Tunnel IPv4**
  - **Tunnel IPv6**
- Use the **trash** button to clear everything, or the **upload** button to import a **usque JSON** file.

**If you get rate-limited** (for example Cloudflare error `1015`):

- The tool automatically tries the next API in the pool.
- Wait a few minutes between many consecutive requests.
- Or use the **Manual option**: open one of the API links in a new tab, copy the entire JSON shown, and paste it into the box. All fields fill in automatically.

### Step 2: Choose settings

Select your **client** (by OS tab, then by app), then adjust the options. See the [Settings Reference](#-settings-reference) for what each one does. If you are not sure, **keep the defaults**.

### Step 3: Copy or download the output

- The **live preview** shows the exact config that will be exported.
- Press **Copy** to put it on your clipboard, or **Download** to save a file.
- Paste / import it into your client.

## ⚙️ Settings Reference

### General

| Setting | Options | Notes |
|---|---|---|
| **Client** | OS tabs → client list | Decides the output format and which extra options appear |
| **Transport** | **H2** `TCP + TLS1.2` (default) · **H3** `QUIC + TLS1.3` | H2 works over TCP. **H3 requires UDP to be allowed** on your network |
| **Number of configs** | 1 – 10 | For combined endpoints, half are IPv4 and half IPv6 (when both exist) |
| **Routing rules** | **Iran** (default) · **China** | Applies to Clash and v2rayNG / Happ / Streisand. Local sites go direct |
| **Endpoint** | See [Endpoints](#-endpoints) | Single endpoint, random range, or a combined pool |
| **Port** | `8095` · `443` · `8443` · `4443` · `1701` · `4500` · `500` | Try another port if one is blocked |
| **SNI masking** | 24 presets | Default: `www.cloudflare.com` |
| **DNS** | 14 presets | Default: `1.1.1.1, 8.8.8.8` |
| **Name (Shadowrocket)** | Free text | Default: `WARP-MASQUE` |
| **Include tunnel IPv6 address** | On / Off | Turn **off** if your tunnel address is IPv4-only |
| **Fragment masking** | On / Off (default off) | **Turn off** if requests fail or you see a `Mask` error |

### Clash options

| Setting | Notes |
|---|---|
| **Rules source (Geo)** | Choose where geo rule data comes from |
| **H3-L4 mode (low latency)** | Forces a fixed SNI, DoH DNS and UDP off. Uses H3 |

### MahsaNG options

| Setting | Notes |
|---|---|
| **Output** | `masque://` links (one per line) or full **JSON** configs |
| **Noise (wnoise)** | `none` · `quic` · `quicv1` · `quicinit` · `random`. When enabled: count `15`, delay `1-2`, payload size `5-10` |
| **MTU** | Default `1280` |
| **Keep alive** | Default `5` |

Random picks stay the same until you regenerate the key or change the selection.

### Combined pools

| Option | Contents |
|---|---|
| **Combined: IPv4 + IPv6** | Official IPv4 + IPv6, plus US / Germany / Finland IPv6 and backup hosts |
| **Combined: IPv6 only** | Official IPv6 + regional IPv6 + IPv6 backups |

| **Combined: IPv4 (incl. third-party)** | Official IPv4 + IPv4 backup hosts |
| **Combined: ZeroTrust only** | Endpoints for **ZeroTrust accounts** only |

- **Official IPv4:** `162.159.198.2` (primary), `162.159.199.2` (backup)
- **Official IPv6:** `2606:4700:103::2` (primary), `2606:4700:104::2` (backup)
- **Third-party backups:** `masque1.bestcf.eu.cc` and `masque2.bestcf.eu.cc` (IPv4), `masque3.bestcf.eu.cc` and `masque4.bestcf.eu.cc` (IPv6)

## 📦 Output Formats

| Client type | Output |
|---|---|
| **Xray-based desktop clients** | JSON with `log` + `outbounds` |
| **Xray-based mobile clients** | JSON array of full configs, each with DNS (hosts + servers), a `mixed` inbound on port `10808`, routing rules (geo-based direct rules for private / local traffic, UDP/443 blocked), `metrics` on `127.0.0.1:10812`, and outbound traffic stats |
| **Clash (Mihomo)** | Full YAML profile with proxies, `url-test` / `fallback` / `select` proxy groups, rule providers (MetaCubeX `meta-rules-dat`, ACL4SSR AI list), sniffer, TUN settings, fake-ip DNS, and optional chain-proxy providers |
| **Shadowrocket** | Node using your chosen name (default `WARP-MASQUE`) |
| **MahsaNG** | `masque://` links (one per line) **or** JSON configs |

Config names carry the suffix `MASQUE Nav` plus an endpoint label (for example `Official`, `Official IPv6`, `Backup`, `US IPv6`) so you can tell nodes apart at a glance.

## 🛠️ Troubleshooting

| Problem | Fix |
|---|---|
| **"Generate new key" fails / rate limit (`1015`)** | Press again (next API is used automatically), wait a few minutes, or use the **Manual option** |
| **Config imports but no traffic** | Update your client and Xray core to the **latest** version |
| **Requests fail or a `Mask` error appears** | Turn **Fragment masking OFF** |
| **H3 does not connect** | Your network may block UDP. Switch **Transport to H2** |
| **Specific endpoint is blocked** | Try another endpoint, another **port** (`443`, `8443`, `4443`, ...) or a different **SNI** |
| **IPv6 not working** | Turn **Include tunnel IPv6 address OFF**, or pick an IPv4-only endpoint set |
| **Slow / unstable** | Try **H3-L4 mode** (Clash), lower **MTU**, or generate several configs and test them |
| **Clash rule providers don't load** | Pick a different **Rules source (Geo)** |

## 💻 Self-Hosting / Running Locally

The whole project is one static file, so hosting is trivial.

```bash
# 1. Clone
git clone https://github.com/DarknessShade/Masque-Generator.git
cd Masque-Generator

# 2. Serve it (any static server works)
python3 -m http.server 8080
# or
npx serve .
```

Then open `http://localhost:8080`.

**Deploy your own copy on GitHub Pages:**

1. Fork this repository.
2. Go to **Settings → Pages**.
3. Set the source to the `main` branch, root folder.
4. Your copy goes live at `https://<your-username>.github.io/Masque-Generator/`.

> ℹ️ Key generation calls public API workers from the browser, so you need internet access for **Step 1**. Importing an existing key and generating configs works from the page itself.

## 🔒 Privacy & Security Notes

- 🧩 The page is a **static single-file app**: there is no server-side component belonging to this project, and generated configs are built in your browser.
- 🌐 **Key generation is the exception.** When you press **Generate new key**, your browser contacts the public API pool to register a WARP MASQUE account. Those services are third-party. If you want full control, generate your own key with [usque](https://github.com/Diniboy1123/usque) and use the **import** button instead.
- 🔑 **Treat your private key like a password.** Do not post generated configs publicly.
- ✅ **Use official endpoints and official clients whenever possible.** Third-party endpoints and resources may cause privacy leaks or losses.
- 🆓 This tool and its configs are **free**. Beware of anyone selling them, and share the link with your friends instead.

## 🧠 MASQUE چیست؟

**MASQUE** (مخفف Multiplexed Application Substrate over QUIC Encryption) مجموعه‌ای از استانداردهای IETF برای تونل‌کردن ترافیک (UDP، IP و HTTP) از طریق HTTP/3 و QUIC است. Cloudflare WARP در کنار WireGuard، پروتکل MASQUE را هم به‌عنوان تونل پشتیبانی می‌کند. از آنجا که ترافیک MASQUE برای اندپوینت Cloudflare شبیه ترافیک عادی HTTPS / HTTP/3 دیده می‌شود، در شبکه‌هایی که هندشیک ساده WireGuard مسدود یا محدود شده، جایگزین مفیدی است.

این ابزار یک اکانت WARP MASQUE را به **outbound برای Xray-core** (و فرمت‌های Clash و Shadowrocket) تبدیل می‌کند تا بتوانید از کلاینت‌هایی که همین حالا دارید استفاده کنید.

## 🧭 راهنمای گام‌به‌گام

### گام ۱: ساخت کلید WARP MASQUE

- روی **Generate new key** کلیک کنید. یک اکانت جدید از مجموعه APIها درخواست می‌شود.
- چهار چیپ API زیر دکمه، وضعیت مجموعه را نشان می‌دهند: نوبت بعدی، استفاده‌شده با موفقیت، یا ناموفق.
- فیلدهای زیر به‌صورت خودکار پر می‌شوند:
  - **Private key (base64)**: کلید خصوصی
  - **Endpoint public key**: کلید عمومی اندپوینت
  - **Tunnel IPv4**: آی‌پی تونل نسخه ۴
  - **Tunnel IPv6**: آی‌پی تونل نسخه ۶
- دکمه **سطل زباله** همه‌چیز را پاک می‌کند و دکمه **آپلود** برای وارد کردن فایل **usque JSON** است.

**اگر با محدودیت (Rate limit) مواجه شدید** (مثلاً خطای `1015` کلودفلر):

- ابزار خودکار API بعدی را امتحان می‌کند.
- بین درخواست‌های پشت‌سرهم چند دقیقه صبر کنید.
- یا از **Manual option** استفاده کنید: یکی از لینک‌های API را در تب جدید باز کنید، کل JSON نمایش‌داده‌شده را کپی کنید و در کادر پیست کنید. تمام فیلدها خودکار پر می‌شوند.

### گام ۲: انتخاب تنظیمات

**کلاینت** خود را انتخاب کنید (اول تب سیستم‌عامل، بعد خود برنامه) و سپس گزینه‌ها را تنظیم کنید. توضیح هر گزینه در بخش [راهنمای تنظیمات](#-راهنمای-تنظیمات) آمده است. اگر مطمئن نیستید، **مقادیر پیش‌فرض را نگه دارید**.

### گام ۳: کپی یا دانلود خروجی

- **پیش‌نمایش زنده** دقیقاً همان کانفیگی را نشان می‌دهد که خروجی گرفته می‌شود.
- با **Copy** در کلیپ‌بورد کپی کنید یا با **Download** به‌صورت فایل ذخیره کنید.
- آن را در کلاینت خود پیست / ایمپورت کنید.

## ⚙️ راهنمای تنظیمات

### تنظیمات عمومی

| تنظیم | گزینه‌ها | توضیحات |
|---|---|---|
| **Client** (کلاینت) | تب سیستم‌عامل ← لیست کلاینت‌ها | فرمت خروجی و گزینه‌های اضافی را تعیین می‌کند |
| **Transport** (ترنسپورت) | **H2** ‏`TCP + TLS1.2` (پیش‌فرض) · **H3** ‏`QUIC + TLS1.3` | H2 روی TCP کار می‌کند. **H3 نیاز دارد UDP در شبکه‌تان آزاد باشد** |
| **Number of configs** (تعداد کانفیگ) | ۱ تا ۱۰ | در اندپوینت‌های ترکیبی، نیمی IPv4 و نیمی IPv6 است (اگر هر دو موجود باشند) |
| **Routing rules** (قوانین مسیریابی) | **Iran** (پیش‌فرض) · **China** | روی Clash و v2rayNG / Happ / Streisand اعمال می‌شود. سایت‌های داخلی مستقیم باز می‌شوند |
| **Endpoint** (اندپوینت) | بخش [اندپوینت‌ها](#-اندپوینتها) | تکی، رنج تصادفی یا مجموعه ترکیبی |
| **Port** (پورت) | `8095` · `443` · `8443` · `4443` · `1701` · `4500` · `500` | اگر یک پورت بسته بود، پورت دیگری را امتحان کنید |
| **SNI masking** | ۲۴ پریست | پیش‌فرض: `www.cloudflare.com` |
| **DNS** | ۱۴ پریست | پیش‌فرض: `1.1.1.1, 8.8.8.8` |
| **Name (Shadowrocket)** | متن آزاد | پیش‌فرض: `WARP-MASQUE` |
| **Include tunnel IPv6 address** | روشن / خاموش | اگر آی‌پی تونل شما فقط IPv4 دارد، **خاموش** کنید |
| **Fragment masking** | روشن / خاموش (پیش‌فرض خاموش) | اگر درخواست‌ها شکست خورد یا خطای `Mask` دیدید، **خاموش** کنید |

### گزینه‌های Clash

| تنظیم | توضیحات |
|---|---|
| **Rules source (Geo)** | منبع داده‌های قوانین جغرافیایی را انتخاب کنید |
| **H3-L4 mode (low latency)** | SNI ثابت، DNS از نوع DoH و UDP خاموش را اعمال می‌کند. از H3 استفاده می‌کند |

### گزینه‌های MahsaNG

| تنظیم | توضیحات |
|---|---|
| **Output** (خروجی) | لینک‌های `masque://` (هر خط یکی) یا کانفیگ کامل **JSON** |
| **Noise (wnoise)** | `none` · `quic` · `quicv1` · `quicinit` · `random`. در صورت فعال بودن: تعداد `15`، تأخیر `1-2`، اندازه payload برابر `5-10` |
| **MTU** | پیش‌فرض `1280` |
| **Keep alive** | پیش‌فرض `5` |

## 🎯 اندپوینت‌ها

منوی اندپوینت همه گزینه‌ها را یک‌جا دسته‌بندی کرده است.

### رنج‌های تصادفی (به ازای هر انتخاب ساخته می‌شود)

| گزینه | رنج |
|---|---|
| **Range IPv4** (پیش‌فرض) | `162.159.198.0/24` |
| **Range IPv6** | `2606:4700:103::/64` |
| **Range IPv4 + IPv6** | هر دو مورد بالا |

آی‌پی‌های تصادفی تا وقتی کلید را دوباره نسازید یا انتخاب را عوض نکنید، ثابت می‌مانند.

### مجموعه‌های ترکیبی

| گزینه | محتوا |
|---|---|
| **Combined: IPv4 + IPv6** | آی‌پی‌های رسمی IPv4 و IPv6، به‌علاوه IPv6 آمریکا / آلمان / فنلاند و میزبان‌های بکاپ |
| **Combined: IPv6 only** | IPv6 رسمی + IPv6 منطقه‌ای + بکاپ‌های IPv6 |
| **Combined: IPv4 (official only)** | ‏`162.159.198.2` و `162.159.199.2` |
| **Combined: IPv4 (incl. third-party)** | IPv4 رسمی + میزبان‌های بکاپ IPv4 |
| **Combined: ZeroTrust only** | فقط اندپوینت‌های مخصوص **اکانت‌های ZeroTrust** |

### اندپوینت‌های تکی

- **IPv4 رسمی:** ‏`162.159.198.2` (اصلی)، `162.159.199.2` (پشتیبان)
- **IPv6 رسمی:** ‏`2606:4700:103::2` (اصلی)، `2606:4700:104::2` (پشتیبان)
- **بکاپ‌های شخص ثالث:** ‏`masque1.bestcf.eu.cc` و `masque2.bestcf.eu.cc` (برای IPv4)، `masque3.bestcf.eu.cc` و `masque4.bestcf.eu.cc` (برای IPv6)
- **میزبان‌های IPv6 منطقه‌ای:** آمریکا، آلمان، فنلاند

> ⚠️ **استفاده از اندپوینت‌های رسمی توصیه می‌شود.** اندپوینت‌های شخص ثالث فقط برای راحتی ارائه شده‌اند. بخش [نکات حریم خصوصی و امنیت](#-نکات-حریم-خصوصی-و-امنیت) را ببینید.
