## 📖 About | درباره پروژه

**Masque-Generator** is a seamless, easy-to-use web interface designed to generate and manage configurations for the new **WARP MASQUE** protocol. Say goodbye to manual config editing! With this tool, you can automatically fetch keys, customize routing, and export ready-to-use configs for your favorite proxy clients.

**ماسک جنریتور** یک ابزار تحت وب ساده و در عین حال قدرتمند برای ساخت کانفیگ‌های پروتکل جدید **WARP MASQUE** است. با این ابزار دیگر نیازی به ساخت دستی کانفیگ‌ها ندارید! به راحتی کلید (Key) دریافت کنید، کلاینت خود را انتخاب کنید، تنظیمات دلخواه را اعمال کرده و کانفیگ خروجی را کپی کنید.

---

## ✨ Features | ویژگی‌ها

- 🔑 **One-Click Key Generation**: Automatically requests a new WARP MASQUE key from an integrated API pool.
- ⚡ **H2 & H3 Support**: Choose between `[H2] TCP + TLS1.2` or `[H3] QUIC + TLS1.3` for maximum stability and speed.
- 🌍 **Smart Geo-Routing**: Built-in routing profiles for **Iran** and **China** (Local websites go direct!).
- 🛡️ **Fragment Masking**: Advanced obfuscation options to bypass DPI (Deep Packet Inspection).
- 🎛️ **Advanced Tweaks**: Options for IPv6/IPv4 tunnel addresses, combined endpoints, and H3-L4 low latency mode for Clash.
- 📱 **Fully Responsive UI**: Works flawlessly on both mobile devices and desktops.

## 🚀 Quick Start | شروع سریع

1. **Open the App**: Visit the [Live Web App](https://darknessshade.github.io/Masque-Generator/).
2. **Generate Key**: Click the "Generate" button in Step 1 to fetch a fresh WARP MASQUE key (or manually import your JSON key).
3. **Customize Settings**: Select your preferred client (e.g., v2rayNG), choose the protocol (H2/H3), and pick your routing (Iran/China).
4. **Copy & Connect**: Copy the final configuration from Step 3 and paste it into your proxy client. You are good to go! 🌐
